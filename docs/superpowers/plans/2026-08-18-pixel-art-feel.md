# Pixel Art Feel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render the game at a true 480×270 pixel resolution (integer-scaled ×4 into the unchanged 1920×1080 window) with placeholder sprites, a purple→peach damage-erode shader, and a pixel font — keeping UI text sharp.

**Architecture:** `canvas_items` stretch mode drops the game's coordinate space to 480×270 while fonts still rasterize at window resolution. Enemies/drops swap `_draw` rects for `Sprite2D` children showing generated 4-color PNGs; enemy damage becomes a palette-swap shader (`hp_ratio` uniform) that recolors purple pixels to peach left-to-right. All world tunables rescale ÷4.

**Tech Stack:** Godot 4.5.1 (GDScript, gdshader, text `.tscn`), no external tools — placeholder PNGs are generated by a Godot script.

**Spec:** `docs/superpowers/specs/2026-08-18-pixel-art-feel-design.md`

func _write(path: String, rows: Array) -> void:

	img.save_png(path)
	print("wrote ", path)

### Task 3: Damage-erode shader + enemy sprite

Enemies render as the sprite; damage recolors purple pixels to peach left-to-right via a shader, replacing the `_draw` HP bar. Wander/bounce/hit logic is untouched.

**Files:**
- Create: `shaders/enemy_damage.gdshader`
- Modify: `enemy.gd` (full new version below)

**Interfaces:**
- Consumes: `res://sprites/enemy.png` from Task 2; `Palette`.
- Produces: shader uniform contract `hp_ratio: float` (1.0 = full HP → all purple, 0.0 = dead → all peach); `enemy.gd` keeps its existing public surface (`died` signal, `get_rect()`, `on_target_fired(rect)`, `take_damage(amount)`) — `main.gd` needs no changes.

- [ ] **Step 1: Write `shaders/enemy_damage.gdshader`**

```glsl
shader_type canvas_item;
// Erodes the enemy's purple body to peach, left to right, as HP drops.
// Purple stays right-anchored (like the old HP bar): hp_ratio 1.0 = all
// purple, 0.0 = all peach. Outline/transparent pixels pass through.
// Colors are Palette.PURPLE / Palette.PEACH (shaders can't read GDScript).

uniform float hp_ratio : hint_range(0.0, 1.0) = 1.0;

const vec3 PURPLE = vec3(0.439216, 0.341176, 0.611765);
const vec3 PEACH = vec3(0.878431, 0.588235, 0.658824);

void fragment() {
	vec4 tex = texture(TEXTURE, UV);
	if (tex.a > 0.0 && distance(tex.rgb, PURPLE) < 0.02 && UV.x < 1.0 - hp_ratio) {
		COLOR = vec4(PEACH, tex.a);
	} else {
		COLOR = tex;
	}
}
```

- [ ] **Step 2: Replace `enemy.gd` with the sprite/shader version**

Full new file contents:

```gdscript
class_name Enemy
extends Node2D
## Wandering enemy sprite. Same size as the targeting area (for now).
## Damage is shown by the enemy_damage shader: the purple body erodes to
## peach left to right (fully purple = full HP, fully peach = dead).

signal died(at_position: Vector2)

const SPRITE := preload("res://sprites/enemy.png")
const DAMAGE_SHADER := preload("res://shaders/enemy_damage.gdshader")
const SPEED_MIN := 20.0
const SPEED_MAX := 40.0
const DIRECTION_TIME_MIN := 1.0
const DIRECTION_TIME_MAX := 3.0

var max_hp: int
var hp: int
var _velocity := Vector2.ZERO
var _direction_time := 0.0
var _sprite: Sprite2D


func _ready() -> void:
	max_hp = GameState.stats.enemy_max_hp
	hp = max_hp
	_sprite = Sprite2D.new()
	_sprite.texture = SPRITE
	var mat := ShaderMaterial.new()
	mat.shader = DAMAGE_SHADER
	mat.set_shader_parameter("hp_ratio", 1.0)
	_sprite.material = mat
	add_child(_sprite)
	_roll_direction()


func _process(delta: float) -> void:
	_direction_time -= delta
	if _direction_time <= 0.0:
		_roll_direction()
	global_position += _velocity * delta
	_bounce_off_edges()


func get_rect() -> Rect2:
	var size: Vector2 = GameState.stats.target_size
	return Rect2(global_position - size / 2.0, size)


func on_target_fired(target_rect: Rect2) -> void:
	if target_rect.intersects(get_rect()):
		take_damage(GameState.stats.damage)


func take_damage(amount: int) -> void:
	hp = maxi(hp - amount, 0)
	_sprite.material.set_shader_parameter("hp_ratio", float(hp) / float(max_hp))
	if hp == 0:
		died.emit(global_position)
		queue_free()


func _roll_direction() -> void:
	_velocity = Vector2.RIGHT.rotated(randf() * TAU) * randf_range(SPEED_MIN, SPEED_MAX)
	_direction_time = randf_range(DIRECTION_TIME_MIN, DIRECTION_TIME_MAX)


func _bounce_off_edges() -> void:
	var half: Vector2 = GameState.stats.target_size / 2.0
	var bounds := get_viewport_rect().size
	if global_position.x < half.x or global_position.x > bounds.x - half.x:
		_velocity.x = -_velocity.x
	if global_position.y < half.y or global_position.y > bounds.y - half.y:
		_velocity.y = -_velocity.y
	global_position.x = clampf(global_position.x, half.x, bounds.x - half.x)
	global_position.y = clampf(global_position.y, half.y, bounds.y - half.y)
```

Notes for the implementer: `_draw` and every `queue_redraw()` call are intentionally gone — the sprite renders itself, and the shader uniform only changes inside `take_damage`. The sprite is not scaled to `stats.target_size`; the hitbox still reads stats (target-size upgrades are a targeting-area concern — the target/enemy size split is separately deferred, see CLAUDE.md).

```gdscript
class_name CurrencyDrop
extends Node2D
## Placeholder currency: small peach sprite that pops out of a dying enemy.
## Collected (self-frees) when the targeting area passes over it, but only
## after the pop finishes — otherwise a kill under the reticle would
## auto-collect the drop the frame it spawns.

const SPRITE := preload("res://sprites/drop.png")
const SIZE := Vector2(4, 4)
const POP_DURATION := 0.2

var target: TargetingArea
var _collectable := false


func _ready() -> void:
	var sprite := Sprite2D.new()
	sprite.texture = SPRITE
	add_child(sprite)


func pop_to(dest: Vector2) -> void:
	var tween := create_tween()
	tween.tween_property(self, "position", dest, POP_DURATION).set_trans(Tween.TRANS_QUAD).set_ease(Tween.EASE_OUT)
	tween.finished.connect(func() -> void: _collectable = true)


func _process(_delta: float) -> void:
	if _collectable and target and target.get_rect().intersects(get_rect()):
		GameState.add_currency(GameState.stats.currency_per_kill)
		queue_free()


func get_rect() -> Rect2:
	return Rect2(global_position - SIZE / 2.0, SIZE)
```

(`_draw` and the `Palette` references are gone; the 4×4 sprite is centered by `Sprite2D`'s default, matching `get_rect`.)
